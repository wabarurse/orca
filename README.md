# orca

install bun and tmux, then follow the [install steps](docs/REFERENCE.md#2-install-once). run `orca` from your repo’s default branch, sign in with `/login codex` (also `/login claude` if using claude), and choose a model with `/models`.

Upgrading an existing installation? See [the rename notes](docs/REFERENCE.md#upgrading-to-orca) to keep your saved logins and conversations.
