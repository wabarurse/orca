# Adaptive workflow evaluation

Run `bun evals/adaptive/run.ts [output-directory]`. Every case runs in its own process with temporary state, scripted providers and local child processes. No provider credentials, real user projects, publication, deployment or installed application are used.

The cases exercise ordinary delegation without task/review creation, same-branch feedback, fresh context with full history retained, source-attributed corrections and clear behavior, scoped instructions and lazy skills, partial tool-call termination, durable CI observations, edited-schema upgrades, stale file revisions, process yielding, stdin order, exit failures, timeout, cancellation, readiness, output caps, lost supervisors, workspace write isolation, usage attribution, stream reconstruction, bounded recovery and branch ownership.

Each case reports pass/fail and elapsed test time; detailed assertions and logs remain accessible. This is a reproducible runtime regression evaluation. Scripted providers do not establish model judgment, user satisfaction, or comparative token savings. The existing efficiency harness is the separate path for live model/cost comparisons; rerun comparable tasks and report all foreground, summary, search, retry and worker usage before claiming lower cost or higher quality.
